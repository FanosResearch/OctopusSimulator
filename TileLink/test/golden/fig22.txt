# Link implied: level TL-UH, every message single-beat; w, sizes and masks not drawn (the scenario
# uses w=8, size 3, mask 0xff). Name: L0.
# Four "//" breaks, in the drawn cycles 4, 8, 12, 16; each counted as one cycle. a_ready, d_ready HIGH
# from c1 on; every beat accepted. Every response is drawn ONE cycle after its request: the
# simulator's minimum latency, no +1 variant. Cycle convention as in fig06.txt.
# a_param of the PutFullData and the Get is drawn as don't-care; it is reserved (0) and written 0.
# Messages (caption: Prefetch with intent to write; Put storing 0x1; Atomic add of 0x1 returning 0x1;
# Atomic swap of 0x3 returning 0x2; Get loading 0x3), all at address 0x0:
#   c1  Intent         param 1 (PrefetchWrite)        -> c2  HintAck
#   c5  PutFullData    data 0x1                       -> c6  AccessAck
#   c9  ArithmeticData param 4 (ADD)  data 0x1        -> c10 AccessAckData data 0x1 (old value; memory 0x2)
#   c13 LogicalData    param 3 (SWAP) data 0x3        -> c14 AccessAckData data 0x2 (old value; memory 0x3)
#   c17 Get                                           -> c18 AccessAckData data 0x3
# The data story is consistent with a real memory (unlike Figure 18), so the whole data column is
# compared. Data values are the little-endian word of the active lanes.
