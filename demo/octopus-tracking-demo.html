Every job's release and finish cycle is replayed from a cycle-accurate Octopus run of the same localization task (demo/run_acts.sh: snoop MESI, 32 KB inclusive LLC, MCsim DDR4 with FR-FCFS). Time is shown in simulated cycles, played back at the rate set above. Act 3's protection is exactly what Octopus models: a Round-Robin bus arbiter and one LLC way reserved for core 0 (way_partition). The robot's path is a pure function of when jobs finish: it steers toward the goal using the pose estimate of the last finished job. Keys: 1 2 3 switch acts, space pauses.
