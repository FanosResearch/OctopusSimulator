\chapter{Command line, scripts and environment}\label{app:cli}

\section{The simulator}

\begin{lstlisting}[style=shell]
./build/Octopus_Simulator -s <SystemClass> [-p "<key>=<value>"]...
\end{lstlisting}

\begin{description}
\item[\code{-s <name>}] the system to build: a C++ class in \file{src/SystemConfigurations/} and
  its CSV of the same name in \file{configuration/SystemConfigurations/}. \code{MultiCoreSystem}
  (bus) and \code{MultiCoreSystem\_Mesh} ship.
\item[\code{-p "<key>=<value>"}] override one configuration key; repeat for several. The key
  carries its type suffix and, for an instance, its index or \code{[*]}
  (\cref{ch:configuration}). Values with spaces or semicolons need the quotes.
\end{description}

The parser (\code{CLParser}) pairs each \code{-x} with the argument that follows it, so
\code{-p key=value} and \code{-p "key=value"} are the same; it prints every argument it saw at
start-up. The one key every run needs is \code{workload\_path(s)}: a directory holding
\code{trace\_C<n>.trc.shared} per core (or \code{task\_C<n>.task.csv} for a periodic task); the
reports are written into \code{<workload>/newLogger/}.

\section{Environment variables}

\begin{table}[htbp]\centering\small

\begin{tabularx}{\textwidth}{@{}>{\ttfamily\raggedright\arraybackslash}p{0.4\textwidth}Y@{}}
\toprule \normalfont variable & effect \\ \midrule
OCTOPUS\_TRACE=<file> & write the raw event trace (\cref{ch:monitoring}) \\
OCTOPUS\_TRACE\_WINDOW=t0:t1 & keep only trace events inside this core-cycle window \\
OCTOPUS\_EVENT\_DUMP=N & print the raw Logger timelines of the first $N$ slow requests (Total above the threshold, or any memory-bus crossing) \\
OCTOPUS\_EVENT\_DUMP\_MIN=<cycles> & the Total threshold for the dump (default 100) \\
OCTOPUS\_EVENT\_DEBUG=1 & report any request whose stages do not tile to Total, and the end-of-run ok/fail/noresp tally \\
OCTOPUS\_NO\_LOG=1 & skip per-request logging; still write \code{Summary.csv} \\
OCTOPUS\_HANG\_DUMP=<cycles> & dump every controller that has been idle with a non-empty queue for that long, and finalize the trace \\
MCSIM\_PROBE=<file> & log every MCsim request, command and completion with the DRAM clock \\
