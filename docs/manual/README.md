# The Octopus reference manual

`octopus-manual.pdf` is the book-form reference for the simulator: sixteen chapters and four
appendices, every figure in `docs/imgs/` plus the ones drawn here, the configuration keys and
the shipped FSM tables generated from the tree at build time. The PDF is committed so that
nobody needs TeX to read it; rebuild it when the sources or the figures change.

## Building

```shell
bash docs/manual/build.sh            # figures, generated tables, latexmk; writes octopus-manual.pdf
bash docs/manual/build.sh --force-figures   # re-render every SVG
make -C docs/manual                  # the same, and `make clean`
```

Needs a TeX distribution with `latexmk`, `pdflatex`, `biber` and `pdfcrop` (MiKTeX and
TeX Live both ship them) and the packages listed in `preamble.tex` (IBM Plex fonts,
`tcolorbox`, `tikz`, `pgf-umlsd`, `adjustbox`, `biblatex`, `imakeidx`, …; MiKTeX installs
missing ones on first use). Python 3 with Pillow is not needed; Python 3 alone runs the
generators. Headless Chrome is used only to render `figures/svg/*.svg` to `figures/pdf/`; the
rendered PDFs are committed, so a machine without Chrome builds the manual as long as it does
not touch the SVGs.

## Layout

| path | what |
|---|---|
| `octopus-manual.tex`, `preamble.tex` | the driver and the style (fonts, palette, boxes, macros) |
| `chapters/NN-*.tex`, `chapters/A-D-*.tex` | one file per chapter and appendix |
| `figures/svg/` | copies of the SVG figure series (the originals stay in `docs/imgs/`) |
| `figures/pdf/` | their renders, committed |
| `figures/paper/` | vector figures reused from the Octopus papers |
| `figures/tikz/` | figures drawn for the manual, TikZ |
| `figures/png/` | the raster originals |
| `generated/` | `config_keys.tex` and `fsm_*.tex`, regenerated by `build.sh` |
| `tools/` | `svg2pdf.py`, `gen_config_tables.py`, `gen_fsm_tables.py` |
| `references.bib` | the bibliography |
| `build/` | latexmk's aux directory, git-ignored |
