# Publications and citation

## Cite Octopus

Please cite:

> M. Hossam, S. Hessien, and M. Hassan, “Octopus: a Cycle-Accurate Cache
> System Simulator,” *IEEE Computer Architecture Letters*, 2024.

Use the publisher's [IEEE record and full text](https://ieeexplore.ieee.org/document/10633788)
for the canonical bibliographic metadata.[^1]

```bibtex
@article{hossam2024octopus,
  title   = {Octopus: A Cycle-Accurate Cache System Simulator},
  author  = {Hossam, Mohamed and Hessien, Salah and Hassan, Mohamed},
  journal = {IEEE Computer Architecture Letters},
  year    = {2024}
}
```

## Related work

The project includes a maintained list of papers evaluated on Octopus and
protocols re-implemented in it. See the source
[PUBLICATIONS.md](https://github.com/FanosResearch/OctopusSimulator/blob/stable/PUBLICATIONS.md).

To add a publication, open an issue or pull request with the paper title, venue,
year, persistent link or DOI, and a short explanation of how Octopus was used.

[^1]: M. Hossam, S. Hessien, and M. Hassan, “Octopus: a Cycle-Accurate Cache System Simulator,” *IEEE Computer Architecture Letters*, 2024. [IEEE Xplore](https://ieeexplore.ieee.org/document/10633788).
